# University C Programming Labs & Projects

A centralized repository containing practical lab assignments, algorithm design exercises, data structure implementations, and personal C programs completed during university coursework.

## Project Structure & Contents

### Algorithm Design Labs
* **Sorting & Merging:** Implementations of Merge Sort for arrays and linked lists (`task1.c`, `task2.c`).
* **Advanced Search:** Binary search algorithms and optimized range searches for structured production logs (`binarySearch.c`, `task3.c`).
* **Data Summarization:** Frequency counters and analytical reporting scripts (`task4.c`, `max_min.c`).

### Semester 1 Programming Labs
* **Core Fundamentals:** Basic syntax corrections, floating-point math calculations, and custom area calculators (`area_calculator.c`).
* **Arrays & Control Flow:** Multi-dimensional array processing (`M_Arrays.c`) and interactive sequence generators (Fibonacci lab tests).
* **Dynamic Memory:** Heap memory allocation exercises utilizing `malloc()` and `free()` for safe runtime resource management (`labtest10.c`).
* **Control Logic:** Random number guessing games and iterative CLI loops.

### Personal Utilities & Experiments
* **Euclidean Calculators:** Standard Euclidean algorithm and Extended Euclidean algorithm for calculating greatest common divisors and Bézout coefficients.
* **Rotating ASCII Bagel:** A customized ASCII-art rendering script using 3D rotation mathematics, z-buffering, and standard POSIX timers (`Bagle2_0.c`, `rotating_bagel.c`).

## Tech & Requirements
* **Language:** C (C99 / C11 standard)
* **Compiler:** GCC or any standard C compiler supporting standard libraries (`stdio.h`, `stdlib.h`, `math.h`, `string.h`)
* **Environment:** POSIX-compatible terminal (Linux / Fedora)
